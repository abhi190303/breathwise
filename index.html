BreatheWise AI — System Architecture & Production Setup

1. Architectural Overview & Grounded AI Design

BreatheWise AI solves the gap between raw environmental numbers and actionable personal health protection. It combines live Open-Meteo atmospheric telemetry (PM2.5, PM10, CO, NO2, SO2, O3, Temperature, Humidity, Wind Speed) with a user sensitivity profile engine and a dual-mode AI Reasoning Assistant.

2. Free AI Proxy Security (Express / Next.js)

In production, route /api/assistant through your server using free-tier environment variables (GROQ_API_KEY or GEMINI_API_KEY): 

// POST /api/assistant (Groq Free Tier Proxy)
const res = await fetch("https://api.groq.com/openai/v1/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.GROQ_API_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    model: "llama-3.3-70b-versatile",
    messages: [{ role: "system", content: groundedPrompt }, { role: "user", content: question }]
  })
});

3. Resilience, Caching & Zero-Fabrication Policy

  • Intelligent TTL Cache: City telemetry is cached in-memory for 10 minutes to respect Open-Meteo rate limits.
  • Graceful Degradation: If offline or rate-limited (HTTP 429), the app automatically switches to calibrated baseline data or the deterministic reasoning engine.
  • Anti-Hallucination Guardrails: Both free LLM prompts (Groq / Gemini) and the local reasoning engine cite exact µg/m³ readings and avoid medical diagnosis.
